Our Merge Conflict

During our team's Git workflow, we did not encounter a merge conflict. Each team member tried to push README at the same time but no conflict occured.

Because no conflict occurred, there were no conflict markers such as <<<<<<<, =======, or >>>>>>> to resolve.

Git was able to merge the changes automatically because the changes made by the team members did not overlap in the same lines of the same files. Therefore, Git could determine how to combine the changes without requiring manual conflict resolution.
